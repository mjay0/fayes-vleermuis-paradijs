# Fayes Vleermuis Paradijs

Letterspel voor groep 2, voor de iPad (Safari, als app op het beginscherm).
Faye hoort een klank en zoekt de letter. Met sterren koopt ze unicorns,
vleermuizen en versiering voor haar paradijs.

- **Spelvormen:** Kies de letter (3 tot 6 kaarten), Letter-toetsen (hele alfabet), Vleermuizen vangen.
- **Klanken:** papa spreekt ze één keer in (⚙️ → Klanken inspreken). Ze worden lokaal op de iPad bewaard. Zolang een klank er nog niet is, vraagt de stem: "Welke letter hoor je vooraan bij *maan*?"
- **Slim oefenen:** per letter een box van 0 tot 5. Letters die nog lastig zijn, komen vaker. Gaan alle letters goed, dan komt er vanzelf een nieuwe bij.
- **Uitbreiden:** een nieuwe oefening is een nieuw bestand in `js/modules/` (zie `letters.js` voor de vorm), dat je toevoegt aan `js/modules/index.js`.
- **Geen build-stap, geen frameworks, geen accounts.** Alle data blijft op het apparaat.
- **Bij elke nieuwe versie:** verhoog `CACHE` in `sw.js`.

Opbouw en werkwijze: zie de overdracht van Henry's Feestje (`LewisRekenen/OVERDRACHT.md`).
